| Symbol / Token | Canonical Term | Formal Mathematical & System Definition |

| $\boldsymbol{\mu}$ (`mu_prior`) | **[[Term_Prior_Distribution\|Prior Mean Vector]]** | The $D$-dimensional baseline expectation vector ($\boldsymbol{\mu} \in \mathbb{R}^D$) where [[Term_Prediction_Error\|Prediction Error]] is zero |
| $\boldsymbol{\Pi}$ (`pi_precision`) | **[[Term_Precision_Weighting\|Precision Weighting Vector]]** | The inverse variance vector ($\Pi_d = \sigma_d^{-2} \in \mathbb{R}_+^D$) governed by finite conservation $\sum_{d=1}^D \Pi_d = \Pi_{\text{budget}}$ |

| `COMPLEMENTARY_DELEGATION` | **[[Term_Complementary_Delegation\|Complementary Delegation]]** | SAT directive when precision asymmetry $\Delta\Pi$ dominates: high-$\Pi$ agent sets the standard ($u^*_d \approx \mu_{\text{high}}$) and low-$\Pi$ delegates |
| `INTERFACE_DECOUPLING` | **[[Term_Interface_Decoupling\|Interface Decoupling]]** | SAT directive when baseline divergence $\Delta\mu$ dominates: keep internal processes independent and synchronize strictly via a shared interface schema |
| `FRICTIONLESS_EXIT_SORTING` | **[[Term_Frictionless_Exit\|No-Fault Sorting]]** | UNSAT directive when $\lvert \mu_A - \mu_B \rvert > r_A(t) + r_B(t)$: separate into parallel niches without penalty |
